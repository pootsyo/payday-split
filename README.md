# Payday Split

A small offline budget app: enter the month's income, list bills by the account they're paid from, and see how much to move into each account, plus what's left to spend or save.

Data is stored only on the device (browser storage). Use Settings > Save backup file to keep a copy.

The root files are the built app served by GitHub Pages. `src/` holds the source; the root `index.html` is `src/head.html` + `src/app.html`.
